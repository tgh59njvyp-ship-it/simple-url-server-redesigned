アカウント — ログインすると履歴をクラウドに保存できます（端末を変えても見られます）
クラウド保存を使うには、最初に1回だけ設定が必要です（Supabaseに履歴用テーブルを作成）

Supabaseダッシュボードで対象プロジェクト（vxdfcrgpwjsfjsdpdlzj）を開き、SQL Editorに以下を貼って実行してください。あわせて Authentication → Providers で GitHub / Google を有効化し、Authentication → URL Configuration の Redirect URLs にこのページのURLを追加するとログインできます。

create table if not exists public.user_items (
  user_id uuid primary key references auth.users(id) on delete cascade,
  items jsonb not null default '[]'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.user_items enable row level security;
create policy "user_items_own" on public.user_items
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
